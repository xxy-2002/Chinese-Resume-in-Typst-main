# 面试准备

本目录用于整理基于 `2026_6.typ` 版本简历的面试准备内容，重点围绕 2026 年 6 月简历中的经历与能力展开。

## 覆盖范围

- 实习经历：以京东、Moatable、Momenta 三段实习为主，梳理业务背景、个人职责、技术方案、难点问题、结果产出与可追问点。
- 项目经历：以 `Skill Factory` 项目为核心，准备项目背景、系统设计、关键模块、优化思路、评测闭环与可量化成果表达。
- 基础知识：围绕简历中涉及的后端工程、Agent 与 RAG、模型微调与强化学习、数据库、缓存、并发、网络、Docker、Linux 等方向补充八股与延展问题。

## 使用原则

- 所有准备内容默认以 `2026_6.typ` 中的表述为基准，避免与其他版本简历混用。
- 优先沉淀可以直接用于面试表达的内容，包括自我介绍、项目介绍、追问回答与技术细节拆解。
- 重点区分“我做了什么”“为什么这样做”“效果如何”“还有哪些可以优化”。

## 后续建议结构

- `internships/`：按公司拆分实习面试题与回答。
- `projects/`：按项目拆分项目介绍、系统设计和深挖问题。
- `fundamentals/`：整理基础知识问答、常见八股和场景题。
- `self-intro/`：整理自我介绍、项目串讲和面试开场表达。

## 当前定位

当前文件夹作为 2026 年 6 月简历的面试准备主目录，后续新增内容应尽量围绕该版简历持续扩展。

## 已初始化内容

- `internships/`：收录实习相关材料与项目背景说明。
- `projects/`：收录大模型应用、Agent、记忆机制、强化学习相关项目资料。
- `fundamentals/`：收录 Go、MySQL、Redis、操作系统、计算机网络等基础知识资料。
- `general/`：收录综合型面试准备文档与已有整理稿。
- `resume-reference/`：收录当前准备所对齐的简历参考版本。

详细来源与迁移记录见 `MIGRATION_INDEX.md`。
